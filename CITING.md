# Cite SpectralAudit in research

If this software is used in a paper, dissertation, benchmark, or other scholarly
output, **please cite the software and credit its author, Eduardo J. Barrios**.
GitHub displays a **Cite this repository** control from the root `CITATION.cff`.

Suggested reference (adapt year and version to the *actually used release*):

> Barrios, E. J. (2026). *SpectralAudit: Explainable Spectral Forensics for Music and
> Mastered Audio* (Version 0.3.0) [Computer software].
> https://github.com/edujbarrios/spectralaudit

Suggested BibTeX:

```bibtex
@software{barrios_spectralaudit_2026,
  author = {Barrios, Eduardo J.},
  title = {SpectralAudit: Explainable Spectral Forensics for Music},
  year = {2026},
  version = {0.3.0},
  url = {https://github.com/edujbarrios/spectralaudit}
}
```

The Apache-2.0 license *requires preservation of applicable notices on redistribution*;
it does **not** legally compel every research publication to cite the software. This
citation is an academic request and a responsible scholarly practice, not an extra
restrictive licensing term. Do not claim otherwise.

A citable archived DOI can be added after the first release via Zenodo's GitHub
integration, if the author chooses to enable it. Do not invent a DOI.
