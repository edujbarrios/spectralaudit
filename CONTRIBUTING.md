# Contributing

Contributions are welcome. Open an issue before substantial design changes.
Install `python -m pip install -e '.[dev]'`, then run `pytest -q` and `ruff check .`.

Add numerical tests for each DSP change and provide references for new methods.
Do not copy code from projects with incompatible/non-commercial licenses.
Include SPDX-consistent copyright/attribution notices when appropriate.
All submitted changes are offered under the repository's Apache-2.0 license.
